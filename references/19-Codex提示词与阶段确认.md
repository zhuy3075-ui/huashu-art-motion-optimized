# 19 · Codex 提示词与阶段确认

用于改写阶段提问、用户索要调用提示词，或批量任务需要统一协作方式时。面向用户在 Codex 中选择的 GPT-6 系列整理，采用按需读参考、明确产物和完成条件、版本化确认。参考[OpenAI 的 GPT-6 Astra 技能与提示词建议](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)（核对2026-10-09）；不自动切模型、设置推理等级或调用 OpenAI API，没有跨系列性能提升测评。

## 阶段提问契约

每个实际需要确认的节点必须先展示产物，再提出**具体确认问题**；“以上是大纲”这种陈述不算询问。问题带阶段、版本、推荐及未定取舍，允许用户修改/拒绝。一次只留下一个清晰确认对象；批量可以明确列多个同类对象，不能混合待审全文、画风和样片让一句“好”全放行。沿用已有确认与00号明确委托，不为了提问重复已完成环节。

下面是问题形状，内容必须随素材和回答改写，不能照抄固定问卷：

| 节点 | 展示内容 | 实际确认提问示例 |
|---|---|---|
| 需求简报 | 受众、核心效果、内容范围、素材与规格建议 | “简报v1把重点放在新人理解这个方法；是否采用这个方向？还是你更想突出你那次实际失败经历？” |
| 内容大纲 | 开头→主体→结尾，每段素材和作用 | “大纲v1先用你提供的案例再解释原理，是否按这个顺序写全文？如果希望更快给结论，我可以调整开头。” |
| 完整文案 | 实际全文、重要画面文字、版本、预计时长 | “请确认采用文案v2全文；你指出的那句已修改，结尾是否保留这条行动建议？确认后进入分镜。” |
| 分镜与视觉 | 完整镜头表、选定DNA/角色版本与覆盖项、实际静帧 | “是否采用分镜v1及这张纸纹样稿？我建议保留原角色材质；如果你希望也改成手绘，需先看角色处理样稿。” |
| 声音方式 | 新配/原音频/无旁白、具体平台/音色/读法、试听与合成范围 | “本次是否使用你的自定义音色？这两个实际历史音色哪个更适合这段？选定后是否先生成这句短试听？”已选定时改为核对缺项，不重问音色 |
| 短样片 | 实际可播放片段、所用文案、声线与速度、字幕定位 | “是否采用样片v1的节奏和字幕位置？我建议保留这段阅读停留；如果希望更快，我先改样片再给你看。” |
| 候选整片 | 实际成片、规格与验收结果、残留问题 | “是否选定成片v3为最终版本？若还有字幕或镜头要改，请指出位置，我只更新受影响部分。” |

阶段问题不是新的收费许可。确认声音ID只确认选择；短试听与整段生成仍按实际授权范围执行。火山实际词表与 `segmentStarts`可定位字幕/关键词/镜头节拍；DubbingX音频须实际对齐，不能借用火山另一音轨的时间点。

## 可直接调用的提示词

提示词中的名称/ID均由用户实际库替换；不给用户默认套入示例资产。需要时只读相关参考，明确待确认对象后结束本轮；可以继续不依赖该确认的素材整理或其他任务草稿。

**单片需求引导**

> 使用 huashu-art-motion，根据我提供的素材帮我逐步完善需求。先指出素材中的具体线索，给几个适合这次内容的方向与推荐，用探索式反问帮我选择。简报、大纲、实际全文、分镜画风、声音、样片和候选成片分别展示并询问确认；只推进已确认范围。已有授权沿用，不把选画风当全文通过。

**个人风格与角色复用**

> 分析这些参考帧的 Style DNA，区分实际观察、我的偏好和未知项，输出详细规则及可复用提示词。让我确认实际档案后存本地；制作时调用我选定的风格/角色版本，保留原件与身份，不擅自重新生成角色。当前只做风格分析时，不启动配音与整片。

**火山字幕与可选配音**

> 帮我选本次配音平台，展示真实历史音色并询问自定义音色。采用火山时保留同任务实际词级时间戳、原文SRT和镜头起点；采用DubbingX时先生成我选的声音，再对该音频实际对齐字幕。全文/读法与短试听分别确认；任务超时查原task_id，不重复提交。

**批量系列创作**

> 使用 huashu-art-motion，把我提供的选题做成批量项目。先给任务清单，区分共用风格/角色/音色和单项例外，确认清单后建立本地队列。逐项完成简报、大纲与全文，给我实际版本确认；可合并明确列出的同阶段确认。按next逐项调用现有工具，保留任务、产物和确认记录；失败续查原任务，暂时阻断一项时处理其他已授权项。未确认的全文不配音，未选定的新音色先问。全部任务待确认时给汇总并结束本轮。

**继续批量任务**

> 读取这个项目的批量状态和已有产物，核对最新用户确认，只推进下一项可做工作。先恢复在途媒体任务；已完成版本不重做，变更只回退受影响阶段。给我待确认版本与具体问题，不重复采访已确定的内容。
